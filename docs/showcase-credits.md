# Showcase screenshots and credits

The README's three screenshots show the normal LonelySky game. They document
the visual techniques and link to the live game. They are not produced by the
minimal SDK example or used as engine runtime assets.

Apache-2.0 covers engine source. The screenshots also depict the game's branding,
UI and separately credited artwork. The engine does not distribute the game's
planetary maps or sky texture as standalone assets.

Third-party imagery depicted in the screenshots:

- Jupiter, Saturn and ring textures: **Solar System Scope / INOVE**,
  [texture collection](https://www.solarsystemscope.com/textures/),
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The game uses the
  maps unchanged, then projects, lights and composites them in a scene.
  These are observation-based, artist-adjusted maps.
- Background sky: **NASA/Goddard Space Flight Center Scientific Visualization
  Studio**, visualization by **Ernie Wright (USRA)**; star catalog data
  **ESA/Gaia/DPAC**. [Deep Star Maps 2020, #4851](https://svs.gsfc.nasa.gov/4851/).
  The game converts the published EXR's linear RGB to sRGB JPEG for its sky.
  The source is a star-catalog visualization, not a single telescope photograph.
  [NASA media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)
  apply; no endorsement is implied.
- Moon texture: **NASA's Scientific Visualization Studio**, **Ernie Wright (USRA)**,
  with LRO/LROC instrument-team data. [CGI Moon Kit, #4720](https://svs.gsfc.nasa.gov/4720/).
  The game uses its observation mosaic for small rocky and icy bodies. The same
  NASA media guidelines apply.

The screenshots include original artistic compositions, shader effects,
lighting, exposure and scale. They contain no player identities, personal
messages or journey backups.
